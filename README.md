# 💰 My Wallet — Expense Tracker

A simple, modern, and responsive expense tracker built using **HTML, CSS, and JavaScript**. My Wallet helps users track their income and expenses, manage transactions, and understand their spending in one place.

## ✨ Features

- **Dashboard:** View total balance, total income, and total expenses.
- **Add Transactions:** Record income and expenses with an amount, category, date, and description.
- **Transaction History:** View your recorded transactions.
- **Delete Transactions:** Remove transactions when needed.
- **Search Transactions:** Find transactions quickly.
- **Filter Transactions:** View transactions based on their type.
- **Data Persistence:** Transactions are saved in the browser using Local Storage.
- **Responsive Design:** Works on desktop, tablet, and mobile screens.
- **No API Key Required:** The application works without an external API.

## 🛠️ Technologies Used

- **HTML5** — Structures the application.
- **CSS3** — Provides styling, layout, and responsive design.
- **JavaScript** — Handles transaction management and calculations.
- **Browser Local Storage** — Saves transaction data locally.

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/saira172917/expense-tracker.git
   ```

2. Open the project folder:

   ```bash
   cd expense-tracker
   ```

3. Open `index.html` in your browser.

   Alternatively, open the folder in Visual Studio Code and use the **Live Server** extension to run the project.

No additional packages, API keys, or backend server are required.

## 💡 How It Works

1. Add income or expense transactions.
2. Enter the amount, category, date, and description.
3. View the updated balance and financial summary.
4. Search, filter, or delete transactions.
5. Reopen the application to access saved transactions in the same browser.

Transaction data is stored locally in the browser. It is not automatically synchronized across devices or browsers.
